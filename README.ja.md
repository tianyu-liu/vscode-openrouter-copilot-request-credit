# Copilot 用 OpenRouter：カスタムリクエストとクレジット確認

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

Copilot Chat で複数の OpenRouter API キーを使えます。名前付き接続ごとにキー、リクエスト設定、モデルグループ、支出履歴を個別に管理します。この拡張機能は固定の OpenRouter API（`https://openrouter.ai/api/v1`）に接続します。

## インストールとクイックスタート

[Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=tianyu-liu.openrouter-copilot-request-credit) からインストールまたは更新します。VSIX を使う場合は、VS Code の拡張機能メニューで **VSIX からインストール…** を選び、リリースの VSIX ファイルを指定します。

1. コマンドパレットから **OpenRouter: プロバイダーを管理** を実行するか、ステータスバーの OpenRouter アイコンをクリックします。
2. **設定 → グループ管理** で **OpenRouter: RC** を選び、OpenRouter API キーを入力して **接続を保存** を選びます。キーを追加する場合は **接続を追加** を選び、別の名前とキーを入力して保存します。
3. Copilot Chat で、使いたいキーに対応するグループからモデルを選びます。同じモデルでキーを切り替えるには、別のグループからそのモデルを選びます。

0.4.1 から更新すると、既存のキー、リクエスト設定、コンテキストの選択、支出履歴が **OpenRouter: RC** に引き継がれます。更新後に **OpenRouter: プロバイダーを管理** を開くと、VS Code のプロファイルにモデルグループを作成するか、既存のグループを接続に紐づけます。

## 接続とリクエストの管理

- **設定 → グループ管理** で接続の名前や有効状態を変更できます。保存済みのキーを保持するには入力欄を空欄にし、削除するには **キーをクリア** を選びます。キーを入れ替えた後や接続を再び有効にした後は、Copilot でモデルを選び直してください。名前の変更後も選び直しが必要な場合があります。VS Code でグループが削除されたり名前が変更されたりした場合は、**モデルグループを修復** を選びます。
- 各接続のタブでは、クレジット使用量やセッション支出の確認、モデルの表示設定、OpenRouter プリセットの選択ができます。プリセットを選ぶと、その接続に保存されたリクエストが置き換わります。リクエストに使う接続は、Copilot で選んだモデルによって決まります。
- [OpenRouter Request Builder](https://openrouter.ai/request-builder) でリクエスト JSON を作成し、対象の接続タブの **カスタムリクエスト** に貼り付けて **リクエストを保存** を選びます。プロバイダーのルーティング、サンプリング、キャッシュなどの設定は、リクエストをクリアまたは置き換えるまでその接続に適用されます。モデル、メッセージ、ツールは Copilot が指定します。

### ステータスバー

OpenRouter アイコンの横に `$12.40 | $8.20` のように金額が並びます。カーソルを合わせると、対応する接続名と詳細が同じ順序で表示されます。キーが保存されている有効な接続は既定で表示対象になります。各接続のタブで **この予算をステータスバーに表示する** を切り替えると、表示する接続を選べます。

**設定 → 共通設定 → ステータスバーの表示内容** では **残り**（既定）または **使用量** を選べます。対応する VS Code 設定は `openrouterCopilot.statusBarBudgetDisplay`（`remaining` または `usage`）です。残額は、キーで報告された上限、表示用に設定したローカル上限、または利用可能なアカウント残高に基づきます。サーバー側の上限は OpenRouter が適用します。

### 共通設定

- **使用量の更新間隔** の既定値は 5 分です。
- **出力予約** は返信用のトークン数を確保します。OpenRouter に信頼できる出力上限がない場合、コンテキストウィンドウの 12.5% を目安に、16,384～262,144 トークンの範囲で予約します。信頼できる出力上限は上限値のみで制限します。**出力予約** の **既定値に戻す** で 3 つの値をリセットできます。
- **プロンプト保護** は既定で有効です。メッセージ、推論、ツールの引数から長い base64 風の文字列を取り除きます。画像添付は保持されます。

## Copilot で使える機能

- モデルピッカーには料金、コンテキストと出力の上限、対応機能が表示されます。**このキーでは使用できないモデルを非表示** は既定で有効です。OpenRouter から利用可否を取得できない場合は、カタログ全体を表示します。
- 対応モデルでは、ストリーミング、ツール呼び出し、画像入力、推論トレース、モデルピッカーでの推論強度やコンテキストサイズの設定を利用できます。
- **セッション支出** では、各接続の最近のチャットの費用をプロバイダーとモデル別に確認できます。上流プロバイダーへの BYOK リクエストで OpenRouter が費用をゼロと報告した場合、上流の費用が報告されていればその値を使います。

モデルを利用できるかどうかは、Copilot のハーネスとウィンドウの種類によって異なります。WSL、SSH、Dev Containers などのリモートウィンドウでは、Copilot ハーネスに拡張機能のモデルが表示されない場合があります。[VS Code の issue 348630](https://github.com/microsoft/vscode/issues/348630)

## プライバシー

- 拡張機能は、選択した接続のキーで OpenRouter に推論リクエストを送信します。リクエストには、Copilot が渡すメッセージやコンテキスト、添付画像、ツールの定義や実行結果、適用されるリクエスト設定が含まれる場合があります。アカウント、利用可能なモデル、クレジット、プリセットの照会にも対応する接続のキーを使います。OpenRouter は推論を上流のモデルプロバイダーにルーティングします。[OpenRouter のプライバシーポリシー](https://openrouter.ai/privacy)
- 認証情報は API キー欄に入力してください。VS Code は各キーを SecretStorage に個別に保存します。リクエストのテンプレートと支出記録（費用の紐づけに使うチャット ID を含む）は現在の VS Code プロファイル専用のローカルデータベースに保存されます。利用可能な場合、パネルは VS Code のローカルのセッションファイルから Copilot のチャットタイトルを読み取り、支出項目のラベルに使います。
- Copilot からチャット ID が渡された場合は、その ID をもとに OpenRouter の `session_id` を生成します。一部の補助リクエストでは、同じ接続とワークスペースの最近のチャット ID を使う場合があります。Agent SDK のリクエストでは利用可能なチャット ID がない場合があります。紐づけ先がないリクエストは `session_id` を付けずに送信し、報告された費用は **未割り当て** に計上します。
- VS Code の拡張機能開発ホストでのみ、`OPENROUTER_RC_DEBUG=1` を設定すると拡張機能のログディレクトリの `openrouter-requests.jsonl` にリクエストの本文を書き込みます。ログには機密性のあるプロンプト、ツールの内容、画像が含まれる場合があります。
